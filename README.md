# Introduction to AI Engineering — companion repository

*The Skills You Need to Become an AI Engineer*, by Mohamed Miled.

This repository holds every dataset, script and solution used in the book. The code for every chapter is given in **Python** and in **R**, side by side.

## The two worlds of the book

Half of the book's examples come from **structured finance**, half from **asset management**. All firms, deals, funds, borrowers and issuers are fictional; the file layouts follow real regulatory and market templates.

| Folder | What it holds | Template it follows |
|---|---|---|
| `data/sf/rmbs/` | *Larkfield Mortgage Funding 2025-1 PLC*: 2,000-loan UK prime RMBS, 16 monthly loan-level tapes (June 2025 to September 2026), loan cash flows, note balances, monthly priority of payments, deal terms, prospectus excerpt | Annex II (RREL/RREC fields) of Delegated Regulation (EU) 2020/1224, as onshored in the UK |
| `data/sf/auto/` | *Redwater Auto Receivables Trust 2025-A*: US auto loan asset-level file, September 2026 | SEC Regulation AB II, Schedule AL, auto loan fields |
| `data/am/` | *Harbourline Asset Management*: three funds (global equity, euro corporate bond, balanced multi-asset), security master, 36 months of returns, holdings, NAVs, benchmarks, transactions, issuer ESG data, sector attribution | Industry-standard holdings and performance files |
| `data/am/documents/` | Factsheets, PRIIPs Key Information Documents, SFDR Article 8 periodic disclosure | PRIIPs KID (Delegated Regulation (EU) 2017/653); SFDR Annex IV (Delegated Regulation (EU) 2022/1288) |

The full field-by-field description is in [`docs/data_dictionary.md`](docs/data_dictionary.md).

## Regenerate the data

The data is generated by two deterministic scripts (seed 2025). Running them again produces identical files.

```bash
python scripts/make_sf_data.py
python scripts/make_am_data.py
```

## Repository layout

```
data/        datasets (structured finance and asset management)
scripts/     data generators
chapters/    code for each chapter, chNN/python and chNN/r
evals/       evaluation sets (questions with checked answers)
agents/      the two final-project agents, in Python and in R
apps/        the two R Shiny applications
docs/        data dictionary
```

## Requirements

Chapter 0 of the book installs everything: Python 3.12 or later, R 4.4 or later, Git, and Ollama for running language models on your own computer at no cost.

# Introduction to AI Engineering — companion repository

*The Skills You Need to Become an AI Engineer*, by Mohamed Miled.

This repository holds every dataset, script and solution used in the book. The code for every chapter is given in **Python** and in **R**, side by side.

## The two worlds of the book

Half of the book's examples come from **structured finance**, half from **asset management**. All firms, deals, funds, borrowers and issuers are fictional; the file layouts follow real regulatory and market templates.

| Folder | What it holds | Template it follows |
|---|---|---|
| `data/sf/rmbs/` | *Larkfield Mortgage Funding 2025-1 PLC*: 2,000-loan UK prime RMBS, 16 monthly loan-level tapes (June 2025 to September 2026), loan cash flows, note balances, monthly priority of payments, deal terms, prospectus excerpt | Annex II (RREL/RREC fields) of Delegated Regulation (EU) 2020/1224, as onshored in the UK |
| `data/sf/auto/` | *Redwater Auto Receivables Trust 2025-A*: US auto loan asset-level file, September 2026 | SEC Regulation AB II, Schedule AL, auto loan fields |
| `data/am/` | *Harbourline Asset Management*: three funds (global equity, euro corporate bond, balanced multi-asset), security master, 36 months of returns, holdings, NAVs, benchmarks, transactions, issuer ESG data, sector attribution | Industry-standard holdings and performance files |
| `data/am/documents/` | Factsheets, PRIIPs Key Information Documents, SFDR Article 8 periodic disclosure | PRIIPs KID (Delegated Regulation (EU) 2017/653); SFDR Annex IV (Delegated Regulation (EU) 2022/1288) |

The full field-by-field description is in [`docs/data_dictionary.md`](docs/data_dictionary.md).

## Regenerate the data

The data is generated by deterministic scripts (seed 2025). Running them again produces identical files.

```bash
python scripts/make_sf_data.py           # Larkfield and Redwater
python scripts/make_am_data.py           # Harbourline funds and documents
python scripts/make_am_db.py             # data/am/harbourline.sqlite (Chapter 11)
python scripts/make_dq_tape.py           # received tape with injected errors (Chapter 12)
python scripts/make_servicer_notes.py    # servicer notes (Chapter 4)
python scripts/make_servicer_reports.py  # servicer reports in PDF (Chapter 16)
python scripts/make_research_notes.py    # research notes (Chapter 17)
python scripts/make_request_log.py       # service request log (Chapter 19)
```


## Corrections of the exercises

The folder `solutions/` holds the corrections of every exercise of the book, chapter by chapter
(start with `solutions/README.md`). They are generated from the book's own source, so each correction
is the same text, code and figures as the printed one. Each has seven parts: what the question asks,
the plan, step by step (with the code explained line by line), reading the result, checking the answer,
mistakes to avoid, and trade-offs. Where a correction prints a script under its path, that script is
in `chapters/` and runs from the repository root.

For the exercises that develop the R Shiny applications (23.1, 23.3, 23.4 and 24.4), the repository goes further
than the book. After the printed correction, a section *Going further on GitHub* gives the complete application
with the change (`apps/solutions/exNN_M/app.R`), every changed line in context, the full test with its output
(`tests/solutions/test_exNN_M.R`) and screenshots (`solutions/img/`). Run the tests from the repository root:

```bash
LANG=C.UTF-8 Rscript tests/solutions/test_ex23_1.R
LANG=C.UTF-8 Rscript tests/solutions/test_ex23_3.R
MOCK_SCRIPT=tools/scripts/ch23_review.json python tools/mock_ollama.py &   # Exercise 23.4 needs the scripted model
LANG=C.UTF-8 Rscript tests/solutions/test_ex23_4.R
Rscript tests/solutions/test_ex24_4.R
```

## Run the final project

From the repository root:

```bash
# tests: no model needed
python tests/test_assistants.py
Rscript tests/test_assistants.R
Rscript tests/test_sf_app.R
Rscript tests/test_am_app.R
python tests/test_solutions_files.py   # scripts in solutions/ = files in chapters/
Rscript tests/test_solutions_files.R

# the applications (Ollama running for the Assistant tab)
Rscript -e 'shiny::runApp("apps/sf_app", port = 8101)'
Rscript -e 'shiny::runApp("apps/am_app", port = 8102)'

# optional: one service for both applications
cd services/r && Rscript -e 'plumber::pr_run(plumber::pr("plumber.R"), port = 8000)'
AIE_SERVICE_URL=http://127.0.0.1:8000 Rscript -e 'shiny::runApp("apps/sf_app", port = 8101)'
```

## Requirements

Chapter 0 of the book installs everything: Python 3.12 or later, R 4.4 or later, Git, and Ollama for running language models on your own computer at no cost.
